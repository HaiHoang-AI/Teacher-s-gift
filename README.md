# Dòng chảy 9+ — Tri ân thầy Nguyễn Huy Hoàng

Cuốn scrapbook nhỏ của lớp 12V1 — Dòng chảy 9+ gửi thầy Nguyễn Huy Hoàng nhân ngày Nhà giáo Việt Nam 20/11.

Mỗi chương mượn không khí một tác phẩm văn học trong chương trình Ngữ văn THPT: *Chữ người tử tù*, *Hai đứa trẻ*, *Sóng*, *Tây Tiến*, *Đàn ghi ta của Lorca*, bia Tiến sĩ ở Văn Miếu và *Tràng giang*.

## Xem trên máy

Trang là HTML tĩnh, không cần cài đặt gì. Mở bằng một server tĩnh bất kỳ, ví dụ:

```bash
python -m http.server 8000
```

rồi vào http://localhost:8000.

## Cấu trúc

- `index.html`: toàn bộ trang (bản cuộn dọc)
- `assets/img/`: ảnh của lớp, sticker, băng washi, nền giấy
- `assets/audio/giai-dieu-9.mp3`: bài hát "Giai điệu 9+"

Một số tranh minh hoạ tác phẩm (`assets/img/tp-*.jpg`) lấy từ internet và thuộc bản quyền của tác giả gốc.
